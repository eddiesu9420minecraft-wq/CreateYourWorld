**Create Your World. · Free Forever. — by pikara™**

Pikara 軟體管理中心的第一個 alpha 版本。永遠免費：無訂閱、無付費解鎖、無強制廣告。

### 內容
- 啟動畫面與主視窗的無縫轉場、品牌介面
- 從 GitHub Releases 取得真實版本、可斷點續傳的下載佇列、SHA-256 驗證
- 安裝、啟動、更新、回復、解除安裝；首個整合產品為 Pikara Science Studio
- Pikara Secure Network：DNS over HTTPS（Cloudflare / Google）、只使用 HTTPS、嚴格驗證憑證、主機允許清單
- 安全自動更新：已簽章的 update.json（公鑰內建於程式）、防降級與重放攻擊、SHA-256 加 minisign 簽章驗證

### 已知限制
- **macOS 版沒有 Apple 簽章，也未經公證。** 第一次開啟會被 Gatekeeper 阻擋：請在 App 上按右鍵選「打開」，或執行 `xattr -dr com.apple.quarantine "/Applications/Create Your World.app"`。
- macOS 版由 GitHub Actions 編譯。除非 docs/TESTING.md 列出實機測試結果，否則**尚未在實機上測試**。
- 共用運行環境（Python、FFmpeg、Whisper、llama.cpp）尚未開放。
- 尚未發布 Linux 版。

所有檔案的校驗值列在 `SHA256SUMS.txt`。安裝包以 Pikara 發布金鑰簽章（minisign，金鑰 ID `13216449EEB947A5`）。
