### 新增：開發工具與 runX
- 「所有應用程式」新增「全部／應用程式／開發工具」分頁。
- 新產品 **runX**（原創程式語言與 AOT 原生編譯器 runxc），列在「開發工具」。
  - 預設使用 Alpha 頻道。
  - 安裝前必須通過 GitHub digest、SHA256SUMS 與 Pikara 發布金鑰簽章三項驗證。
- **加入 PATH**：
  - 把命令列工具目前版本的執行檔複製到 CYW 的 `bin` 資料夾，並把該資料夾加入**使用者** PATH，不需要系統管理員權限。
  - 更新、切換版本、回復與解除安裝時都會自動跟著處理。
  - 加入後請開新的終端機視窗。
- 命令列工具沒有視窗，所以提供「加入 PATH／從 PATH 移除」與「開啟資料夾」，而不是「開啟」。

### 新增：介面動畫
- 頁面切換、側邊欄、卡片、對話框、通知與進度條都有動畫。動畫只使用 transform／opacity，閒置時不耗用資源。
- 「設定 → 介面 → 介面動畫」可以選擇：跟隨系統（預設，遵守系統的「減少動態效果」）、開啟或關閉。

### 已知限制
- **macOS 版沒有 Apple 簽章，也未經公證**；macOS 的自動更新與 PATH 功能（`~/.local/bin`）尚未在 Mac 實機上測試。
- 加入 PATH 時寫入使用者真實 PATH 的步驟，自動測試是在測試用登錄機碼上驗證的。

所有檔案的校驗值列在 `SHA256SUMS.txt`。安裝包以 Pikara 發布金鑰簽章（minisign，金鑰 ID `13216449EEB947A5`）。
